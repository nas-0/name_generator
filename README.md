Full stack application (currently in the works) that generates name based on a language or country

## ⚙️ Required Environment Variables

Before running the app, create a `.env` file in the project root with the following variables:

| Variable         | Description                            | 
|------------------|----------------------------------------|
| `DEEPSEEK_API_KEY`   | DeepSeek APIKEY         |
| `DEEPSEEK_URL`     | DeepSeek URL   |
| `DATABASE_URL`          | Database URL             |
